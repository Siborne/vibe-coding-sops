# 当前仓库启用 AGENTS 规则

## What

- 新增仓库根目录 `AGENTS.md`，把 `docs/agents-md/programming/AGENTS.md` 的编程协作规则落到本仓库。
- 按本仓库实际情况填写项目事实：
  - 静态 Markdown + Bash 仓库，没有应用运行时、包管理器、自动化测试和构建命令。
  - 验证方式改为 `git diff --check`、相对链接检查、`bash scripts/generate-stats.sh` 和 diff 审核。
- 增加本仓库专用规则：
  - `rules/` 下的规则全部适用。
  - 每次修改文件都要在 `docs/变更记录/` 新增记录。
  - 新增规则/技能按 `CLAUDE.md` 步骤补齐 rationale、README 和 `CLAUDE.md` 索引。
  - 修改 `SKILL.md` 时同步 `.claude/skills/` 副本。
  - `stats.json` 只由脚本生成。
  - 不提交 `.claude/settings.local.json`、`.reasonix/`、`garden-skills/`、`reference/` 等本地内容。

## Why

用户要求把编程版 `AGENTS.md` 的内容加入当前项目，让仓库自身的 AI 协作规则不再只存在于模板目录里。直接复制模板会带入「可复制模板」的说明和未填写的项目事实，因此需要按本仓库实际结构改写，并把本仓库已有的规则维护流程写进根文件。

## Before / After

**Before**：仓库没有根目录 `AGENTS.md`，AI 编程规则只存在于 `docs/agents-md/programming/AGENTS.md`，且那份文件明确标注为模板。

**After**：根目录 `AGENTS.md` 是本仓库的实际协作规则，包含真实项目事实、验证流程和本仓库专用维护要求；模板文件继续保留，供其他项目复制。
