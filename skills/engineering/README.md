# Engineering Skills（工程类）

工程类技能面向软件工程协作与开发流程，Agent 按既定流程逐步执行，每一步都有可验证的产出。

## 子类体系

| 子类 | 定义 | 技能 |
|------|------|------|
| `git-collaboration` | Git 协作与版本控制流程 | [github-pr-workflow](git-collaboration/github-pr-workflow/SKILL.md) |
| `code-quality` | 代码质量保障（测试、lint、重构） | （规划中） |
| `testing` | 测试策略与用例编写 | （规划中） |
| `delivery` | 构建、部署与发布 | （规划中） |

## 收录标准

核心是"固定流程 + 可验证产出"。与用户的交互以执行为主、对话为辅，流程不允许跳步。
