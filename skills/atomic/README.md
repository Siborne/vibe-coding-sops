# Atomic Skills（原子类）

原子类技能是单一主题、职责最小、可独立调用、可与其他技能组合的最小技能单元。

## 当前技能

| 技能 | 说明 |
|------|------|
| [agent-prompt-engineering](agent-prompt-engineering/SKILL.md) | 为 AI Agent 应用编写提示词的 5 种工程化技巧 |

## 收录标准

- 单一主题，不混入多个流程
- 可独立使用，也可被复合技能调用
- 内容以技巧/知识单元为主，而非多阶段工作流
